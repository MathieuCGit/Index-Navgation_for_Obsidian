# Changelog

All notable changes to Navigation Index for Obsidian are documented in this directory.

## Versions

- **[v1.0.1](v1.0.1.md)** - Bug fixes for Obsidian style validation and parser test coverage
- **[v1.0.0](v1.0.0.md)** - Initial release with full indexing, filtering, sorting, and export features

## Format

Each version has its own markdown file following the [Keep a Changelog](https://keepachangelog.com/) format:

- 🎉 **Features** - New functionality added
- 🔧 **Improvements** - Enhancements to existing features
- 🐛 **Bug Fixes** - Issues resolved
- ⚠️ **Breaking Changes** - Changes that affect compatibility

## Reading the Changelog

- Start with the most recent version at the top
- Each version entry includes release date and feature list
- Technical details explain what was changed and why
- Test coverage shows quality and stability improvements

## Contributing

When releasing a new version:

1. Create a new file `vX.Y.Z.md`
2. Include all changes since last release
3. Format according to the [Keep a Changelog](https://keepachangelog.com/) standard
4. Include test coverage information
5. Add entry to this index
